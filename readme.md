# clusteringV3

Инструмент для анализа поисковых запросов с помощью графовых алгоритмов и ИИ.

## Возможности

- **Сборка семантического ядра** — графовый алгоритм выделения ключевых слов
- **Фасетная классификация** — группировка слов через ансамбль LLM-моделей
- **Поиск гипотез** — обнаружение скрытых связей через BFS
- **Гибкие параметры** — 15+ настраиваемых параметров, пресеты
- **Экспорт/импорт** — перенос данных между компьютерами через многотомные архивы

## Требования

- Python 3.10+
- 7-Zip (для сжатия архивов при экспорте)
- API-ключ хотя бы одного LLM-провайдера (для классификации)
